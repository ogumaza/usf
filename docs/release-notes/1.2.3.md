In this release, `usfrip` rips Rowf's Badge Shop in Paper Mario's set as the game plays it in the shop, and adds two Toad Town tracks. Rip Paper Mario again (see below). usf rips Nintendo 64 music into USF, the PSF-family format for the Nintendo 64, and plays it by running the game's code on an emulated console. The release comes with a ripper (`usfrip`), a renderer (`usfplay`), a foobar2000 component and an XMPlay plugin.

## Downloads

| File | Contents |
|---|---|
| `usf-1.2.3-win-x64.zip` | `usfrip` and `usfplay` for 64-bit Windows |
| `foo_input_usfplay-1.2.3.fb2k-component` | the foobar2000 component, for 64-bit and 32-bit foobar2000 v2 |
| `xmp-usfplay-1.2.3.zip` | the XMPlay plugin, for XMPlay 3.8.2 or later |

The programs run on Windows 10 or later and require no runtime DLLs. To install the component, open the file with foobar2000, or add it under Preferences › Components. To install the XMPlay plugin, unzip `xmp-usfplay-1.2.3.zip` and put `xmp-usfplay.dll` in the XMPlay folder, or in a folder inside it. Then restart XMPlay. For macOS, the README explains how to build from source.

## Rip Paper Mario again

Rips of Paper Mario made with 1.2.2 play Rowf's Badge Shop only as the game plays it beside the shop. Rip the game again with this release. Against a rip made with 1.2.2, track 9, "Toad Town, Rowf's Badge Shop", sounds different, and the new set has two more tracks, right after track 15. Every later track therefore gets a number 2 higher, in its file name and in its `track` tag. Apart from that, the other tracks don't change. A rip made with an earlier release differs in more tracks. The notes of the releases in between list them.

## Changes since 1.2.2

### Paper Mario's Toad Town

- "Toad Town, Rowf's Badge Shop" now plays the music as the game does while Mario stands in the shop. The extra instruments play at full level and the rest of the band plays quieter, as inside the five buildings.
- A new track, "Toad Town, outside Rowf's Badge Shop", plays the music beside the shop. In 1.2.2, "Toad Town, Rowf's Badge Shop" played this version.
- A new track, "Toad Town, mix 6 (unused)", plays a set of extra instruments that the song contains but the game never plays. The game sets no level for them. The track plays them at the quieter level that the game uses outside the buildings. That level is a choice.
