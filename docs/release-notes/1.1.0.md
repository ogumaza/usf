In this release, `usfrip` rips the music of Super Mario 64 and of Yoshi's Story, and the music of 11 games of Seta's Aleck64, an arcade board built from the Nintendo 64's chips. usf rips Nintendo 64 music into USF, the PSF-family format for the Nintendo 64, and plays it by running the game's code on an emulated console. The release comes with a ripper (`usfrip`), a renderer (`usfplay`), a foobar2000 component and an XMPlay plugin.

## Downloads

| File | Contents |
|---|---|
| `usf-1.1.0-win-x64.zip` | `usfrip` and `usfplay` for 64-bit Windows |
| `foo_input_usfplay-1.1.0.fb2k-component` | the foobar2000 component, for 64-bit and 32-bit foobar2000 v2 |
| `xmp-usfplay-1.1.0.zip` | the XMPlay plugin, for XMPlay 3.8.2 or later |

The programs run on Windows 10 or later and require no runtime DLLs. To install the component, open the file with foobar2000, or add it under Preferences › Components. To install the XMPlay plugin, unzip `xmp-usfplay-1.1.0.zip` and put `xmp-usfplay.dll` in the XMPlay folder, or in a folder inside it. Then restart XMPlay. For macOS, the README explains how to build from source.

## Changes since 1.0.1

### Super Mario 64's music

- `usfrip` rips the music of Super Mario 64 (USA) as well as its sound effects. The music has a track for each sequence from 0x01 to 0x22. Each track plays at the volume that the game gives its sequence, with the reverb and the voices of the audio set-up that the game uses for it.
- In Dire, Dire Docks, Jolly Roger Bay, Big Boo's Haunt, Hazy Maze Cave and Wet-Dry World, the game fades sets of channels in and out by where Mario is. These levels' music has a track for each mix. The title screen and the water levels also have tracks with the variation that the game plays after a game over and in the Secret Aquarium.
- An image can now have more than one set. `usfrip` writes Super Mario 64's music and its sound effects to two folders inside the output folder: `music` and `sound effects`. `--bgm` rips only the music. `--list` lists the tracks of each set.

### Yoshi's Story

- `usfrip` rips the music of Yoshi's Story (USA). The game plays it through an early form of the sound engine of The Legend of Zelda: Ocarina of Time.
- The game changes some of its music with the Yoshi's health. Each of those pieces has a track for the usual mix, one for the mix with no petals left, and one for the mix with a health above 8.
- One piece has six phases, and each phase plays a different set of channels. It has a track for each phase.
- The rip leaves out the jingle of the boot's logo. In the music that gives each of the eight Yoshis a channel, all eight channels play.

### The Aleck64

- `usfrip` rips the music of these Aleck64 games: Eleven Beat, Hanabi de Doon! - Don-chan Puzzle, Hi Pai Paradise, Hi Pai Paradise 2, Kurukuru Fever, Magical Tetris Challenge, Mayjinsen 3, Star Soldier: Vanishing Earth, Super Real Mahjong VS, Tower & Shaft and Vivid Dolls.
- An Aleck64 game comes as the ROM set of its board, not as a cartridge image. Give `usfrip` the set's ZIP archive, or a folder of its chips. `usfrip` finds each chip of the game by its SHA-1 and size, whatever the file is called, and puts the image together from them. The board's PIF data isn't needed.
- The rips play in the existing USF players, which emulate a plain Nintendo 64. Each Aleck64 profile stops the threads of the game that read the board's inputs or drive its video chip, and the music runs without them. `usfrip` warns if a track still reads or writes the board's addresses after the snapshot.
- Super Real Mahjong VS plays its music in mono or in stereo. A setting in the game's service menu picks which, and the game plays mono until someone changes it. `usfrip` rips both, as the sets `mono` and `stereo`.
- The core emulates the Aleck64 board for the rips: 8 MiB of RDRAM, the CIC-NUS-5101 boot chip, the DIP switches and controls, the coin, service, test and start inputs, and a mahjong panel.

### Other changes

- `usfrip` reads a cartridge image from a ZIP archive, when the image is the only file of the archive named `.z64`, `.v64` or `.n64`.
